# African_Crises_Datase-Data-Cleaning-EDA-with-Pandas

This project focuses on preprocessing and exploratory data analysis (EDA) using the African Crises dataset. The objective is to demonstrate fundamental data cleaning and transformation techniques using Pandas and imbalanced-learn.

📊 **Dataset Overview**

The **African Crises dataset** provides valuable insights into the economic and financial stability of African countries over time. It includes records of banking crises, currency collapses, and sovereign debt defaults, alongside key economic indicators such as GDP, inflation, and foreign reserves.

This dataset offers a rich context for understanding patterns and triggers of financial distress across the continent, making it ideal for practicing data preprocessing, cleaning, and exploratory analysis in real-world scenarios.

🔍 **Project Objectives**

- Preprocessing the Data

- Categorical data encoding using LabelEncoder

- Addressing class imbalance using techniques from the imbalanced-learn library

- Exploratory Data Analysis (EDA)

- Converting column types for consistency

- Indexing and slicing DataFrames

- Using common functions such as value_counts(), replace(), and unique()

- Handling missing values and duplicate records

- Basic data insights through summary statistics

🧰 **Tools & Libraries Used**

- Python

- Pandas

- NumPy

- sklearn

- imbalanced-learn
